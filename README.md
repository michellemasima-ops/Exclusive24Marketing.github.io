# CapeRun

CapeRun is a lightweight, single-page arcade driving prototype set on a fictional Cape Town-inspired night route. It uses plain HTML, CSS, and Canvas JavaScript; there are no libraries, external assets, build steps, or network requests.

## Play

Open `index.html` in a modern browser, or publish the repository as a static website. Press **Start the Run** and survive the 60-second pursuit.

- **Steer:** WASD or arrow keys
- **Accelerate:** W / Up
- **Brake:** S / Down / Space
- **Pause / resume:** P
- On touch devices, use the on-screen arrows and pedals.

The first prototype uses simple original car shapes, generated scenery, and optional synthesized beeps to keep it small and fast. The player car is described as a Ballade i160 in the fictional game; this prototype is not affiliated with any vehicle manufacturer. The chase is arcade-style and contains no weapons. The character identity is intentionally original rather than imitating a real person's appearance or voice.

## Next steps

A sensible next milestone is a second route and a simple checkpoint race. Add only assets with licenses that permit your intended use, and keep attribution where required. Performance depends on the device and browser, so test on the actual low-memory hardware you want to support.
